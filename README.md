# Potion Lab - Full Stack

Monorepo de la Entrega 3 de Ingeniería Web.

- `Backend/`: API REST con Node, Express, MongoDB Atlas y JWT.
- `Frontend/`: aplicación React con Vite y Tailwind.

## URLs públicas

- Frontend: URL_DEL_FRONTEND
- Backend: https://backend-entrega-2.onrender.com
- Swagger: https://backend-entrega-2.onrender.com/api-docs

## Ejecutar en local

1. Backend: ver `Backend/README.md` (crear `.env` desde `.env.example`, `npm install`, `npm run seed`, `npm run dev`).
2. Frontend: ver `Frontend/README.md` (`npm install`, crear `.env` con `VITE_API_URL=http://localhost:4000/api`, `npm run dev`).

Cada carpeta documenta sus variables de entorno y su mapa de endpoints.
